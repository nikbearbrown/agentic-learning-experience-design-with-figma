# Agentic Learning Experience Design with Figma — Outline

**Author:** Nik Bear Brown

---

## Front Matter

- **Copyright** and independent-book notice (not affiliated with or endorsed by Figma)
- **Preface** — how to read this alongside the two Experience Design volumes; the plan-tier table

## Act One — Establish

1. **The Screen That Teaches Nothing** — critique an agent-built learning screen against five learning-design checks.
2. **Wiring the Agent to the Canvas** — connect to the remote MCP server, confirm seat and tier, run a budgeted session.
3. **How the Agent Sees a Frame** — predict what the read drops; map where a rule can live.
4. **From Learning Objective to Screen Inventory** — backward design, stored where the agent reads it.

## Act Two — Build

5. **Variables as Pedagogy: Support Levels as Modes** — fading support as a switch the agent flips.
6. **Item Types the Agent Can't Break** — question components whose descriptions are the rules.
7. **Feedback, Hints, and the Answer You Don't Show** — the item state machine.
8. **Retrieval and Spacing Flows** — prototype the states; annotate the schedule; compare with Make.
9. **Designing Under Cognitive Load** — load rules as tokens plus an automated check.
10. **Accessible Learning Items** — keyboard, screen reader, alternatives, and what the canvas can't prove.
11. **Progress, Mastery, and the Dashboard Problem** — learning evidence over engagement metrics.

## Act Three — Apply

12. **The Rules File** — the library compiled into rules and a review skill.
13. **Testing With Learners, Not Pixels** — a delayed retrieval check, honestly reported.
14. **Handoff: Code, Make, and the LMS** — choose the build path; keep the rules intact.
15. **Capstone: One Lesson, Agent-Built, Learner-Tested** — Chapter 1's score against the final score.
