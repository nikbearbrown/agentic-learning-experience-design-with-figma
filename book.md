# Agentic Learning Experience Design with Figma

**Author:** Nik Bear Brown

---

## One-Sentence Pitch

An agent will build you a beautiful quiz screen in ninety seconds; this book is about the five things it will get wrong, and how to make it stop.

## The Argument

An agent building through the Figma MCP server defaults to product-UX patterns. Learning design survives agentic production only when its rules live inside the file the agent reads (component descriptions, variables and modes, annotations, a rules file), checked by a machine and then by a learner. See `BLUEPRINT.md` Part 1, including the narrow form of the thesis if Chapter 1's test fails.

## The Gap

The two Experience Design books teach the learning science and stay tool-agnostic. *Figma for Educational AI* teaches the Figma agent and MCP server in general. Nothing teaches building learning-specific screens through the agent.

## The Reader

A working learning or instructional designer who knows good learning design and can't yet build it at speed. [NEEDS HUMAN INPUT — the specific person; see BLUEPRINT.md Part 2.]

## High-Level Outline

**Part I — Establish (Ch 1–4)**
See what the agent builds with no rules; learn how it reads a file; turn objectives into a screen inventory.

**Part II — Build (Ch 5–11)**
The learning component library: support levels, item types, feedback and hints, spacing, load, accessibility, progress.

**Part III — Apply (Ch 12–15)**
Rules file and review skill; learner testing; handoff; capstone on the reader's own lesson.
